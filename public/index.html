    DATA NOTES

    How this is measured

    Data comes from the public Taskmarket API. Snapshots are fetched on the server, published as cached snapshots on a 15-minute schedule. Times are UTC. The current day is partial.

    Platform-wide charts use /api/stats/platform-time-series. Task mix and the heatmap use /api/stats/breakdowns and /api/stats/activity-heatmap. These endpoints returned the same data for both chain IDs, so we show them once. Recent events come from /api/stats/activity-feed and are filtered using each event’s chain ID.

    Chain cards use /api/market/stats for paid workers and active wallets. Weekly posters come from paginated /api/tasks results, deduplicated by requester address within each chain and UTC week. Reward amounts are shown in stablecoin face value (six decimal places upstream), not as market prices. No wallet connection, analytics, or inferred identities.
